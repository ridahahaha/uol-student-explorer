# University of Lahore: Student Explorer

An HTML and CSS learning project for **Rida Nawaz**.

## Preview

Open `index.html` in a browser. Keep both photographs and `styles.css` beside it. No JavaScript, package installation or build step is required.

## Pages and sections

This is a single-page website with navigation links to academic areas, university information, campus life, an admissions guide, a practice student form, frequently asked questions and contact details.

## Design and structure

The page has a blue palette, a centered introduction followed by a wide photograph, a two-column academic grid, campus information before the admissions guide and a full-width form. Smaller screens use stacked layouts.

## HTML and CSS study notes

| Concept | Where to look |
| --- | --- |
| Semantic layout | `header`, `nav`, `main`, `section`, `aside`, `footer` |
| Figure and caption | Hero and campus photographs |
| Details and summary | Expandable FAQ answers |
| Mark, abbr and time | Admission notice, footer abbreviation and founding year |
| Blockquote | Learning reminder in the about section |
| Address | Official contact information |
| Progress and meter | Clearly labelled sample indicators above the form |
| CSS Grid | Programme cards, admissions steps and form fields |
| Flexbox | Navigation, action buttons and footer |
| Transitions | Smooth hover feedback |
| Rotate and scale | Monogram, arrows and campus photograph |
| Translate X and Y | Links, cards and buttons |
| Linear gradient | Programme backgrounds |
| Radial gradient | Circular arrow beside the hero photograph |
| Box and text shadow | Hover depth and subtle hero heading shadow |
| Border radius and opacity | Rounded edges and photograph hover state |
| Media queries | Tablet/mobile layout and reduced-motion support |
| CSS `:target` | Form next-steps panel |

## Practice form

Use sample details only. Native HTML checks required fields, email format and the phone pattern. The submit button opens an on-page next-steps message. Inputs intentionally have no `name` attributes, so values are not placed in the GET request. There is no backend, database, login, email delivery, payment processing or official admissions submission. Progress and meter values are illustrative, not live.
